Los tachados se representan mediante `<s>` y permanecen visibles; no son una animación ni contenido de un documento personal. Se mantienen Selectric, los vectores y los colores existentes. Las tildes de esta copia se escriben correctamente en Unicode.

## Idioma de interfaz

El selector ES/EN está en el acceso y en la cabecera de la aplicación. Cambia controles, mensajes, archivo, editor, moviola, entregas y metadatos de la entrada. Nunca traduce títulos, carpetas, documentos ni eventos del autor.

- `resources/js/i18n.ts`: catálogo inglés y selección de idioma; español como texto de origen.
- `LanguageSwitcher.tsx`: control accesible de preferencia.
- Preferencia local: `inkgroove:locale` y cookie `inkgroove_locale`. La cookie no es una credencial; no necesita cifrado. El bloqueo de almacenamiento no impide escribir.
- `?lang=es` y `?lang=en` permiten abrir una entrada en un idioma concreto. El selector actualiza ese parámetro cuando ya existe.
- Cada petición de API envía `Accept-Language`.
- `SetLocale` limita la selección a `es` y `en`. Para HTML considera parámetro, preferencia y navegador; la API utiliza el encabezado del cliente. El fallback de traducción es inglés.
- `lang/es` y `lang/en` contienen los mensajes PHP. La API muestra el primer error de validación pertinente.

Los identificadores de API, atributos de formato, tipos de evento y claves de recuperación conservan sus nombres técnicos. Cambiar idioma refresca decoraciones y controles mediante una transacción sin cambios en el documento, sin evento de escritura y sin recrear el editor. Los ajustes iniciales de Tiptap se mantienen estables entre renders.

## Incidencia de tildes

Reproducción: pegar `gnesis`, situar el cursor después de `g`, iniciar la tecla muerta `´` y completar con `é`. La versión anterior cambiaba la procedencia del carácter provisional antes de `compositionend`; al dividir el nodo DOM, Chromium finalizaba la composición y conservaba una tilde suelta junto a la vocal.

La corrección mantiene el nodo durante la composición, acumula y mapea únicamente los rangos editados y cambia su procedencia al terminar la entrada nativa. Las instantáneas intermedias pueden conservar el estado provisional del teclado; el estado final registra la vocal compuesta y su procedencia definitiva. Se conserva el naranja intacto y el azul sólo para el rango reelaborado. No se normaliza Unicode ni se reescribe historial antiguo.

El fallo se reprodujo en un navegador real y el mismo recorrido produjo `génesis` después de la corrección. Esto no sustituye a comprobar el teclado físico de macOS y Safari tras instalar.

Los errores que ya quedaron guardados como `g´enesis` requieren editar la palabra correspondiente. No aplicar una sustitución masiva de `´` por un carácter combinado: la tilde suelta también puede ser contenido intencional o formar parte de una cita.

## Validación y distribución

`npm run test:browser` utiliza Chromium/Playwright, Vite y una API controlada. Cubre composición nativa, rango de pegado, ES/EN sin reescritura, entrada móvil, guardado/reapertura, Unicode NFC/NFD en ODT y consulta de moviola. PHPUnit cubre los mensajes de idioma y la persistencia real de documentos con SQLite; la CI mantiene además el smoke de MySQL y el arranque Docker del ZIP distribuido.

```sh
# Desarrollo, dentro del repositorio (Node y las dependencias ya instalados):
npx playwright install chromium
npm run test:browser
```

Playwright es una dependencia de desarrollo, no un servicio de producción. SiteGround sigue recibiendo PHP y activos compilados. Docker y el paquete de SiteGround incluyen `lang/`; el verificador rechaza un paquete de SiteGround sin esos catálogos. No hay migración nueva, cambio de claves o datos ni modificación del muro de acceso.

La prueba de navegador entra en la CI antes de publicar. Una ejecución local del navegador o de PHP no confirma la nueva CI, un push o la instalación en los servidores. Registrar esas evidencias cuando se reciban.

El checkout conserva `storage/framework/views/.gitkeep`: la configuración de Laravel calcula la ruta de vistas compiladas con `realpath`, por lo que el directorio debe existir antes de cargarla. La prueba de portada usa `withoutVite()` y debe pasar también en un árbol recién extraído de Git, sin `.env`, vistas compiladas ni recursos frontend generados. El fallo de CI de `fd7ca96` (`Please provide a valid cache path`) se reprodujo en ese árbol; la corrección conserva el directorio vacío en Git, sin incluir cachés.
